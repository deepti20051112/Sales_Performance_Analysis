# Sales Performance Analysis

## 📊 Project Overview

This project focuses on analyzing sales data using Python and presenting key business insights through an interactive Power BI dashboard.

The project includes data cleaning, exploratory data analysis, KPI analysis, and visualization of sales, profit, quantity, regions, categories, and top-performing products.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify top-performing regions and categories
- Analyze monthly sales trends
- Identify top products by sales
- Compare profit across categories
- Create an interactive Power BI dashboard
- Present meaningful business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI

## 📁 Project Files

| File | Description |
|---|---|
| `Sales_Performance_Analysis.ipynb` | Python data analysis and visualization |

## 📈 Dashboard Features

The Power BI dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Monthly Sales Trend
- Sales by Category
- Total Sales by Region
- Total Profit by Category
- Top 10 Products by Sales
- Region and Category filters
- Date filters

## 🔍 Key Results

- Total Sales: **$2.30M**
- Total Profit: **$286.40K**
- Total Quantity: **38K**
- Technology is one of the strongest-performing categories.
- West and East regions show strong sales performance.
- The dashboard helps identify high-performing products and categories.

## 🐍 Python Analysis

The Jupyter Notebook performs:

1. Data loading
2. Data cleaning
3. Missing-value checking
4. Duplicate checking
5. Feature preparation
6. Exploratory data analysis
7. Sales and profit analysis
8. Visualization

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Sales_Performance_Analysis.ipynb` in Jupyter Notebook.
3. Make sure the cleaned CSV file is available.
4. Run the notebook cells step by step.
